# Legend in the Mist — Tag & Status Color Override
<img width="1728" height="791" alt="Screenshot 2026-07-08 at 8 41 48 PM" src="https://github.com/user-attachments/assets/be2c149c-3843-41d9-b8f9-e0c7b8db29c1" />

This module overrides the tag and status colors in the Legend in the Mist Foundry system and allows you to customize the colors to your liking. By default, the only change from the vanllia system is to make negative statuses a darker green color.

Colors settings are also standardized across the system so that they are consistent across character sheets, roll dialogs, the Scene Tags window, and chat cards.

Changes are purely visual and do not alter mechanics or data.
